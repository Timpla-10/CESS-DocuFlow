
# CESS DocuFlow

CESS DocuFlow is a Web-Based Document Management and Tracking System for the College of Education and Social Sciences, MSU at Naawan.

## Features

- Document tracking and status monitoring
- Document submission and approval workflow
- Role-based access for different users
- Notifications and activity updates
- Responsive user interface

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Backend:** Node.js
- **Database:** PostgreSQL

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Timpla-10/CESS-DocuFlow.git
   ```

2. Navigate to the project folder:
   ```bash
   cd CESS-DocuFlow/app
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the application:
   ```bash
   npm run dev
   ```

5. Open `http://localhost:5173` in your browser.
